# 深海之声

**规则只有一条：日语出声，中文给你看。**

助手每条回复写成两段：

```
わかった。じゃあ、これからは本鯨が自分で訳すね。
明白了。那以后本鲸自己翻。
```

插件会：

1. 挑出含假名的那句 → 合成语音
2. 中文那句 → 留在文字里
3. 消息链变成 `[语音][中文]`

## 为什么不让机器翻译

试过 NLLB-600M、M2M100-418M、opus-mt，全部跑通又全部删掉：
翻译模型常驻 600MB，比原来的 kokoro 还重，最后被运存反噬。

助手自己就会翻译，**不需要本地翻译模型**。这是折腾一天换来的结论。

## 服务

- 语音：`data/tts_service/server.py`（VOICEVOX CORE，约 200MB）
- 插件启动时探 8890 端口，没人就自己拉起来
- AstrBot 重启 → 插件重载 → 服务自动回来

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | true | 总开关 |
| `tts_url` | `http://127.0.0.1:8890/tts` | 语音服务 |
| `tts_timeout` | 120 | 合成超时（秒） |
| `voicevox_dir` | `/root/AstrBot/data/voicevox` | 模型目录 |
| `voicevox_model` | `0.vvm` | 四国めたん/ずんだもん/春日部つむぎ/雨晴はう |
| `voicevox_style` | 3 | ずんだもん ノーマル |

## 停顿参数（语音服务里）

| 标点 | 停顿 |
| --- | --- |
| 逗号 | 不念、不停 |
| 句号 | 0.04s |
| 问号 / 感叹号 / 分号 | 0.03s |
| 特殊符号 | 跳过 |
| 括号内容 | 跳过 |

## 排错

```bash
curl http://127.0.0.1:8890/health
grep "深海之声" data/logs/astrbot.log | tail
```

- **没语音**：回复里是不是没写日语？没假名就没东西可念
- **文字只剩一句**：日语和中文要分行写，靠标点切分
- **服务没起来**：看插件日志有没有「语音服务已拉起」

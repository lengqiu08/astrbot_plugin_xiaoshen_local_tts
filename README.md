# 深海之声

**一体化语音插件：插件自己加载 VOICEVOX，不需要任何外部服务。**

规则：**日语出声，中文给你看。**

## 怎么用

回复写成两段：

```
わかった。じゃあ、これからは日本語で話すね。声が先で、文字が後。
明白了。那以后本鲸用日语说。声音在前，文字在后。
```

插件挑出含假名的句子合成语音，中文留在文字里，消息链变成 `[语音][中文]`。

### 两条指令

| 指令 | 作用 |
| --- | --- |
| `音色` / `语音菜单` | 列出 10 个音色，标出当前在用的 |
| `试听 8` | 用编号 8 念一句，不改变默认 |

## 输出格式

| 格式 | 说明 |
| --- | --- |
| `flac`（默认） | 无损，体积大（1 分钟约 4MB），部分客户端可能不当语音条播 |
| `mp3` | 160k，兼容性最好，QQ 一定认作语音条 |

改 `output_format` 即切。**要无损就 FLAC，要稳就 mp3。**

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | true | 总开关 |
| `voicevox_dir` | `/root/AstrBot/data/voicevox` | 模型、词典、onnxruntime 目录 |
| `voicevox_model` | `0.vvm` | 四国めたん/ずんだもん/春日部つむぎ/雨晴はう |
| `voicevox_style` | 3 | ずんだもん・ノーマル（萝莉） |
| `speed` | 1.05 | 语速 |
| `intonation` | 1.0 | 语调起伏 |
| `output_format` | flac | `flac` 无损 / `mp3` 兼容 |
| `bitrate` | 160k | 仅 mp3 有效 |
| `loudness` | -15 | 响度标准（LUFS），越小越响 |
| `volume_gain` | 1.0 | 额外增益（dB），上限建议 +4 |
| `chunk_chars` | 180 | 每条语音字数上限，超了拆多条 |
| `cache` | true | 同文本只合成一次，最多 80 条 |
| `guard_memory_mb` | 200 | 可用运存低于此值跳过配音 |
| `idle_unload_minutes` | 15 | 闲置多久释放模型 |
| `timeout` | 120 | 单条合成超时（秒） |

## 停顿

| 标点 | 停顿 |
| --- | --- |
| 逗号 | 不念、不停 |
| 句号 | 0.04s |
| 问号 / 感叹号 / 分号 | 0.03s |
| 括号内容 | 跳过（不念） |

在 `main.py` 的 `GAP` 字典和 `SENT_SPLIT` 里改。

## 排错

```bash
grep "深海之声" data/logs/astrbot.log | tail
```

- **没语音**：回复里没写日语？没假名就没东西可念
- **文字只剩一句**：日语和中文要按标点或换行分开
- **声音太小/太炸**：调 `loudness` 与 `volume_gain`
- **FLAC 播不了**：把 `output_format` 改成 `mp3`
- **插件不生效**：确认在 `plugin_set` 白名单里

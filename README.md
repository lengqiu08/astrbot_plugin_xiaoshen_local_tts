# 深海之声

**一体化语音插件：插件自己加载 VOICEVOX，不需要任何外部服务。**

规则只有一条：**日语出声，中文给你看。**

## 怎么用

助手回复写成两段：

```
わかった。じゃあ、これからは日本語で話すね。声が先で、文字が後。
明白了。那以后本鲸用日语说。声音在前，文字在后。
```

插件会：

1. 挑出含假名的句子 → 合成语音
2. 中文句子 → 留在文字里
3. 消息链变成 `[语音][中文]`

没有日语（全是中文）的回复不配音，只发文字。

## 为什么是一体化

之前拆成「插件 + HTTP 语音服务」，结果服务被系统杀掉后没人拉起，
就变成"没声音"。现在合成直接在插件里跑，随 AstrBot 生命周期，不会掉。

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | true | 总开关 |
| `voicevox_dir` | `/root/AstrBot/data/voicevox` | 模型、词典、onnxruntime 所在目录 |
| `voicevox_model` | `0.vvm` | 四国めたん/ずんだもん/春日部つむぎ/雨晴はう |
| `voicevox_style` | 3 | ずんだもん ノーマル；春日部つむぎ = 8 |
| `speed` | 1.05 | 语速 |
| `intonation` | 1.0 | 语调起伏，1.2 更活泼 |
| `bitrate` | 96k | 输出码率 |
| `cache` | true | 同文本只合成一次，最多 80 条 |
| `guard_memory_mb` | 200 | 可用运存低于此值跳过配音 |
| `idle_unload_minutes` | 15 | 闲置多久释放模型 |
| `timeout` | 120 | 单条合成超时 |

## 停顿（代码里写死）

| 标点 | 停顿 |
| --- | --- |
| 逗号 | 不念、不停 |
| 句号 | 0.04s |
| 问号 / 感叹号 / 分号 | 0.03s |
| 括号内容 | 跳过（不念） |

改这两组数字在 `main.py` 的 `GAP` 字典和 `SENT_SPLIT`。

## 排错

```bash
grep "深海之声" data/logs/astrbot.log | tail
```

- **没语音**：回复里没写日语？没假名就没东西可念
- **文字只剩一句**：日语和中文要分行或按标点分开写
- **声音太小/太炸**：调 `speed`，或改 `main.py` 里 loudnorm 的 I 值
- **插件不生效**：确认它在 `plugin_set` 白名单里
